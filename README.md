# IMECX

Plataforma web desenvolvida em Django para gestão de candidaturas, participantes e tarefas do IMECX.

## Funcionalidades

- Registo e autenticação de utilizadores
- Verificação por email
- Aprovação de candidaturas
- Dashboard pessoal
- Sistema de tarefas
- Sistema de notificações
- Gestão administrativa
- Perfis de utilizador

## Tecnologias

- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite/PostgreSQL
- Brevo API
